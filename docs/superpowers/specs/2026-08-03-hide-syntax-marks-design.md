# Hide markdown syntax marks (live-preview toggle)

**Date:** 2026-08-03
**Author:** John Moriarty
**Status:** Approved design, ready for implementation planning
**Branch:** johnmoriarty/polish-and-overlay

## Goal

A toolbar toggle that conceals markdown syntax so the document reads like a
rendered document — bold shows bold, headings styled — while remaining fully
editable plain markdown. Obsidian-style live preview: the buffer, undo,
search, copy, and file contents are untouched; hiding is view-layer only.

## Chosen behavior (from brainstorming)

- **Reveal on active line:** any line intersecting the cursor or selection
  shows its raw syntax; everything else is concealed.
- **Mark scope (v1):** headings, emphasis, strikethrough, inline-code marks,
  and links (only styled link text visible; `[`, `](url)` hidden).
- **Toggle placement:** overlay FAB and normal-window `NSToolbar`, with an
  on/off visual state. Persisted preference, applies to all windows.

## Approach

View-layer concealment via `Decoration.replace` in a CodeMirror view plugin
(approach 1 of 3). Rejected alternatives: CSS `display:none` on mark classes
(breaks CM6 geometry measurement — cursor placement and click targets drift;
per-line reveal needs JS anyway) and a rendered HTML preview pane (read-only;
user wants to keep editing in place).

Because concealed marks reappear as real text the moment the cursor reaches
their line, no atomic-range handling is needed — arrow keys never traverse
hidden characters mid-edit.

## Design

### CoreEditor (TypeScript)

- New extension, `src/styling/nodes/conceal.ts`, built with the existing
  `createDecoPlugin` helper (same pattern as `code.ts` / `indent.ts`):
  - Walk the syntax tree over visible ranges; emit `Decoration.replace({})`
    for these node types:
    - `HeaderMark` — plus the single following space in ATX headings.
    - `EmphasisMark` (`**`, `*`, `_`).
    - `StrikethroughMark` (`~~`).
    - `CodeMark` on `InlineCode` only (fenced code blocks out of scope).
    - Links: `LinkMark` (`[`, `]`, `(`, `)`) and `URL` inside `Link` nodes,
      so `[text](url)` renders as just the styled link text. Skip images
      (`Image` nodes) in v1.
  - Skip any decoration whose range lies on a line intersecting a selection
    range (cursor counts as an empty selection).
  - Recompute on selection change as well as doc/viewport change.
- Config flag `hideSyntaxMarks` in `src/config.ts` (default false) +
  extension wiring in `src/extensions.ts` behind a reconfigurable
  compartment, consistent with how `invisiblesBehavior` toggles.
- New web bridge method `setHideSyntaxMarks(enabled: boolean)` in
  `src/bridge/web/config.ts`; Swift-side bridge regenerated by ts-gyb
  during `yarn build`.

### MarkEditMac (Swift)

- New preference `AppPreferences.Editor.hideSyntaxMarks` (UserDefaults,
  default false).
- `EditorViewController` applies the flag on editor ready and exposes a
  `toggleHideSyntaxMarks` action that flips the preference, calls the bridge
  on all open editors, and updates toggle UI state.
- Normal window: new `NSToolbarItem` (eye / eye.slash SF Symbol) reflecting
  on/off state.
- Overlay FAB: sixth button in `EditorOverlayToolbar`. FAB buttons are
  stateless today; this one needs a persistent "active" appearance —
  extend `EditorOverlayToolbar.Action` with an optional state provider so
  the button can render highlighted when the preference is on.

## Non-goals (YAGNI)

- Fenced code blocks, tables, images, footnotes, HTML blocks: syntax stays
  visible.
- No per-window or per-document state; one global preference.
- No menu item or keyboard shortcut in v1 (toolbar/FAB only).
- No widget substitution (checkboxes, rendered images) — conceal only.

## Success criteria

- Toggle on: `# Heading`, `**bold**`, `*italic*`, `~~strike~~`,
  `` `code` ``, `[text](url)` all render without visible syntax; moving the
  cursor onto a line reveals that line's syntax; moving away re-conceals.
- Cursor placement, clicking, and selection behave normally around concealed
  spans (no drift, no dead zones).
- State survives relaunch and applies to every window including the overlay.
- Both toggles (toolbar + FAB) stay in sync and show clear on/off state.
- `yarn build` (lint + ts-gyb + vite) and Xcode ⌘R build clean.
